# Methods checklist by course type

Topic lists rarely name methods; exams test them (calibration: 134082, 134119, 136158).
For each method that fits the course type: which unit uses it, what it shows, what it cannot
show, one data-reading practice item. Skip a method only with a reason (another required
course teaches it in depth → refresher link).

## Molecular biology / gene expression / RNA
Southern · Northern · Western · PCR, RT-PCR, qPCR (ΔΔCt) · Sanger + next-generation sequencing ·
DNase / MNase / nuclease-protection assays · EMSA · reporter assays (luciferase, GFP) · ChIP,
ChIP-seq (tracks, peaks) · RNA-seq (coverage, intron retention, volcano plot) · bisulfite
sequencing · nuclear/cytoplasmic fractionation · CRISPR/Cas9 knockout, dCas9 fusions, base
editing · RNAi/siRNA · cloning: restriction enzymes, ligase, plasmids, cDNA libraries ·
Genome Browser / conservation tracks · motif discovery (MEME).

## Cell biology
Fluorophores, antibodies, immunofluorescence · GFP fusions, live imaging, FRAP · confocal / EM ·
FACS (DNA content, cell cycle) · protease protection of microsomes (topology) · subcellular
fractionation · pulse-chase · co-IP · cell-cycle mutants and synchronization.

## Genetics / human genetics / developmental
Crosses (maternal vs zygotic, complementation, epistasis with opposite phenotypes, suppressor
screens) · pedigrees · RFLP / gel analysis · linkage, LOD · karyotype, FISH, CGH, microarray ·
GWAS · mosaics / clones · laser ablation · lineage tracing · loss/gain of function, rescue.

## Biochemistry / biophysics
SDS-PAGE, ion-exchange, gel filtration · kinetics plots (Michaelis–Menten, Lineweaver–Burk) ·
X-ray vs cryo-EM vs NMR (when to choose which) · spectroscopy, CD, fluorescence · ITC ·
optical / magnetic tweezers, AFM (calibration: equipartition, power spectrum) · single-molecule
FRET · statistical-mechanics tables (state | energy | multiplicity | weight → Z → P).

## Microbiology / virology
Counting: dilutions, CFU, plaque assay, PFU, MOI and Poisson · growth curves · gene transfer
assays · one-step growth curve · virus purification and titration · reverse genetics ·
reassortment.

## Bioinformatics / computational / systems
Alignment (pairwise, multiple) · phylogenetics · RNA-seq and single-cell pipelines · enrichment
(GO) · clustering, PCA / dimensionality reduction · network analysis · ODE simulation ·
image processing.

## Physiology / neuro / endocrinology
Patch clamp, single-channel recording · calcium imaging · electrophysiology (AP, EPSP) ·
ELISA / RIA · TLC · histology · lesion and imaging studies · Neuropixels / optogenetics.
