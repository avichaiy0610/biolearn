# תקן איור מדעי — שיטת העבודה שאביחי אישר

אביחי, 2026-10-25: אחרי אישור איור שרשרת מעבר האלקטרונים — ״מעכשיו נצייר ציורים רק בדרך הזאת״. הכלל חל על איורים מדעיים חדשים ועל אנימציות.

1. **מקור חזותי:** לראות את האיור הרלוונטי בספר המקומי לפני הציור. לתעד ספר, מהדורה, מספר איור ועמוד PDF. ללמוד צורה, טופולוגיה, מדורים ומיקום יחסי. קריאת הטקסט אינה תחליף להתבוננות.
2. **ציור מקורי:** לצייר מחדש, ללא העתקה או מעקב אחר קווי המקור. לצייר מבנים שמבהירים את הביולוגיה: דו־שכבה, חלבון בעל כיוון ומבנה מובחנים, מדורים ונשאים במיקום נכון. לציין הפשטות וקנה מידה.
3. **אבטיפוס מקומי:** תחילה מחוץ לקוד האתר ב־`Project One/visual-lab/`. לשמור את המקור ולהציג השוואת לפני ואחרי. בהשוואת עיצוב לשמר נתונים ותוכן; להפריד הצעות לתיקון מדעי משיפור חזותי.
4. **בדיקה:** להשתמש ב־`He` לעברית וב־`La` ללטינית, להפריד תוויות מקווים, ליצור מקרא ולבדוק צילומי דפדפן במחשב וב־390px. האיור השלם חייב להתאים לרוחב המסך, ללא גלילה פנימית. אפשר להוסיף הגדלה לעיון בפרטים קטנים. לבדוק גם כיווניות, חיתוך וגבולות מסגרת.
5. **אישור ושילוב:** להציג לאביחי את האבטיפוס. לשלב אחרי אישורו ולבדוק שוב בתוך דף היחידה. לפרסם רק לפי הרשאתו ולוודא באתר החי.
6. **ידע לשימוש הבא:** להוסיף כרטיס ידע ב־`visual-lab/`, עם המקור, הכללים, ההפשטות והטעויות הנפוצות. לעדכן זיכרון משותף ו־HANDOFF. אין לסמן נושא כמאומת לפני בדיקה ייעודית.

באנימציה יש להגדיר מצבים, זהויות עקביות ושינוי סיבתי. סידורים חלופיים אינם בהכרח שלבים בזמן. יש לבדוק גם עצירה, מעבר שלבים ו־reduced motion לפי תקן האנימציות הקיים.
