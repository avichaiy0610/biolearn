# גיבוי האנימציות הישנות (אנימציות השלבים)

כל אנימציות השלבים הישנות נשמרות במלואן, גם אחרי שהוחלפו בסרט רציף. אביחי, 25.11: "לא למחוק את הקיימות, שיהיה להן גיבוי בכל מקרה".

## איפה הן
- הקוד: `content/process-scenes/*.ts`. הקבצים לא נמחקו ולא שונו בעבודת האנימציות הרציפות.
- הנתונים באתר: שלבי כל תהליך נשארו בטבלת `Process` במסד הנתונים. לא בוצע `publish-scene` שמחליף אותם.
- הנגן הישן: `components/ProcessAnimation.tsx`. עדיין משמש בכל תהליך שאין לו סרט רציף.

## מה השתנה
- סרט רציף נרשם ב-`components/scenes/registry.ts`, וב-`ProcessVisual.tsx` מוצג רק הוא.
- הלשונית "שלב-אחר-שלב" הוסתרה בעמודים שיש להם סרט רציף.

## שחזור אנימציה ישנה בעמוד מסוים
מוחקים את שורת ה-matcher שלה ב-`components/scenes/registry.ts`. הדף יחזור מיד לנגן השלבים הישן, עם הנתונים הקיימים ממסד הנתונים.

כדי להחזיר רק את הלשונית: ב-`components/ProcessVisual.tsx` מחזירים את מתג "אנימציה רציפה / שלב-אחר-שלב". הגרסה הקודמת נמצאת ב-git, לפני `df5eeb3`.
